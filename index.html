How it works

Same manual, same order. Just easier to follow.

  1. 01

    It follows the manual

    Every step in the manual’s order, every screw and dowel labelled with the part number printed in the bag.

  2. 02

    Nothing is hand-animated

    One file lists each part and each step. The player builds the scene, lays out the box and animates everything from that.

  3. 03

    You can check anything

    Turn it around, slow it down, tap any part to see what it is and where it goes. The drilled holes show where hardware fits.

About

Hi, I’m Dharshan.

I build interactive 3D things for the web. Right now that’s turning flat-pack manuals into guides you can turn around and step through, because nobody enjoys squinting at drawing 37 of 74.

I come up with the idea, decide how it should feel, and test every version until it does. I write the code with Claude Code as a pair programmer, and I’m happy to walk through how any part of it works.
