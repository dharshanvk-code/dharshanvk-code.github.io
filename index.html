Kaputle Workbench

October 2026

A flashlight you can take apart and rebuild. I wanted it to behave like the real thing, so parts only come off in an order that makes sense: the tail cap before the batteries, the head before the bulb.

It only lights up when the circuit is actually complete. Unscrew the tail cap while it’s on and it goes dark. Take the head off and the bare bulb still glows, just without a beam. If you get stuck, a guided build walks you through putting it back together.

9 parts · 7-step guided build · Three.js

Assembly guide player

October 2026

After the flashlight I wondered whether the same idea could work for flat-pack furniture. This player reads one file that lists every part’s size and position, plus the steps in order. From that it builds the whole guide: the parts, the box contents on the floor, and the animation for each step.

The bookshelf is just a file. A different product would be a different file, with no new code. Next I’m testing whether AI can write that file straight from a paper manual.

32 parts · 10 steps · one JSON file
